Worked solutions for question 2 of the week 7 tutorial!

Convert the following decimal numbers into IEEE 754-encoded bit-strings:

a. 2.5

Step 1: rewrite as binary. We can tackle the integer and fraction portion
separately!

Integer portion: 2 = 0b 10

Fractional portion: use repeated multiplication by 2 to find the bit pattern!
NOTE: Python's bin() function cannot accept floats as input, so we can't find
the binary of a fraction that way!

0.5 * 2 = 1.0, therefore first bit is 1
0.0 * 2 = 0.0, therefore 2nd bit is 0 <- would be an infinite loop of just 0s!

Therefore, 2.5 = 0b 10.1

Step 2: Convert to scientific notation in binary
0b 10.1 = 0b 1.01 * 2^1     (reminder: scientific notation just shifts location of decimal point.)

Step 3: Match the IEEE 754 format.

Sign is positive, therefore sign bit = 0
Exponent = 1 + 127 = 128
Mantissa = fractional component (to 23 dp in length) 
         = 0100 0000 0000 0000 0000 000 (spaces added for readability)

Therefore, IEEE floating point representation for 2.5 would be
0 10000000 01000000000000000000000

b. 0.375

Step 1: rewrite as binary:

0.375 * 2 = 0.75
0.75 * 2  = 1.5
0.5 * 2   = 1.0

Therefore 0.375 = 0b 0.011

Step 2: rewrite in scientific notation
0b 0.011 = 0b 1.1 * 2^(-2)

Step 3: Match the parts!
Sign is positive, therefore sign bit is 0.
Exponent = -2 + 127 = 125 = 0b 0111 1101
Mantissa/Fraction = fractional part to 23 places
                  = 1000 0000 0000 0000 0000 000

Therefore, the full bit string is
0 01111101 10000000000000000000000

c. 27.0

Step 1: rewrite in binary (using your preferred method for integers)!

27 = 16 + 8 + 2 + 1 = 0b 11011

Step 2: rewrite in scientific notation
0b 11011 = 0b 1.1011 * 2^4

Step 3: Match the parts!

Sign is positive, therefore sign bit = 0
Exponent = 127 + 4 = 131 = 0b 1000 0011
Mantissa = fractional portion to 23 places
         = 1011 0000 0000 0000 0000 000

Therefore, full bit string is
0 10000011 10110000000000000000000

d. 100.0

Step 1: Rewrite in binary

100 = 0b 1100100

Step 2: Rewrite in scientific notation
0b 1100100 = 0b 0b 1.100100 * 2^6

Step 3: match the parts of the format!

Sign is positive, so sign bit is 0
Exponent = 127 + 6 = 133 = 0b 1000 0101
Mantissa = fraction portion to 23 places
         = 1001 0000 0000 0000 0000 000

Therefore, full bit string is
0 10000101 10010000000000000000000
