Example conversions from decimal to hexadecimal, by hand!

To convert 543 to hex:

1. Convert to binary

543 / 2 = 271 r 1
271 / 2 = 135 r 1
135 / 2 = 67 r 1
67 / 2 = 33 r 1
33 / 2 = 16 r 1
16 / 2 = 8 r 0
8 / 2 = 4 r 0
4 / 2 = 2 r 0
2 / 2 = 1 r 0
1 / 2 = 0 r 1

Number in binary = write remainder bits with top bits
on the right

= 0b1000011111

2. Convert to hexadecimal
0b1000011111
= 0b 0010 0001 1111
= 0x 2    1    F
= 0x21F

Alternative, using python:
1. Start in terminal by running "python3"

2. Useful functions (can take input in any base):
    - Convert number to binary representation: bin(a number), returns a 
    string so remove the quotes!

    - Convert number to hex representation: hex(a number), returns a string
    so remove the quotes!

    - Convert number to octal representation: oct(a number), returns a string
    so remove the quotes! Also, returns with 0o prefix instead of just 0 - remove the o
    if copying into C code somewhere!

    - Convert number to decimal: int(a number)

3. To leave, type "quit".
