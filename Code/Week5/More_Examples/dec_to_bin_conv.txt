To convert 543 to hex:

1. Convert to binary

543 / 2 = 271 r 1
271 / 2 = 135 r 1
135 / 2 = 67 r 1
67 / 2 = 33 r 1
33 / 2 = 16 r 1
16 / 2 = 8 r 0
8 / 2 = 4 r 0
4 / 2 = 2 r 0
2 / 2 = 1 r 0
1 / 2 = 0 r 1

Number in binary = write remainder bits with top bits
on the right

= 0b1000011111

2. Convert to hexadecimal
0b1000011111
= 0b 0010 0001 1111
= 0x 2    1    F
= 0x21F


num_1:  0b 1001 1011
num_2:  0b 0011 0110
output: 0b 1011 1111

&: 0001 0010
|: 1011 1111
^: 1010 1101

num:    0b 0011 0101
output: 0b 1100 1010

num_1: 0b10110
num_2: 0b11101010
output = num_1 & num_2
